    🌍【2026新版】VPS + FinalShell + 3X-UI 搭建个人专属 VPN

    立即观看完整视频


    本期看点：从零开始购买和重装 VPS，使用 FinalShell 连接服务器，安装新版 3X-UI，并配置 VLESS + REALITY 个人专属节点。

    相比旧版教程，新版 3X-UI 安装流程主要增加了以下内容：

    • 可选择 SQLite 或 PostgreSQL 数据库。
    • 自动生成随机面板账号、密码和访问路径。
    • 可随机生成面板端口。
    • 支持为公网 IPv4 直接申请 SSL 证书。
    • IP SSL 证书有效期约 6 天，并由 acme.sh 自动续期。
    • 新安装会自动尝试配置 Fail2ban。
    • 面板管理菜单、SSL 管理和防火墙功能更加完整。

    🚨 本文仅供网络技术学习、个人隐私保护和远程访问使用。请遵守所在地法律法规、VPS 服务商条款及相关网络管理规定，不得用于违法活动或向公众提供未经授权的服务。

    🔗 视频相关链接

    开始前请准备好下面这些工具：

    • 服务器（VPS）配置推荐-已实测+使用反馈：https://lanyun122.github.io/blog/recommend/1-vps/
    • FinalShell 官方网站：https://www.hostbuf.com/
    • Windows 客户端 v2rayN：https://github.com/2dust/v2rayN
    • Android 客户端 v2rayNG：https://github.com/2dust/v2rayNG
    • 网络测速工具：https://www.speedtest.net/
    • IP 信息检测：https://www.ip2location.com/
    • 交流群：https://telegram.me/+BwyeTrhg9NQ5MjVl

    建议尽量从软件官网或官方 GitHub 下载，避免使用来源不明的所谓“绿色版”“破解版”。

    第一步：购买并重装 VPS

    购买一台带有独立公网 IPv4 的 VPS，个人使用建议配置：

    CPU：1 核及以上
内存：1GB 及以上
硬盘：10GB 及以上
系统：Ubuntu 24.04 LTS
公网 IP：必须有独立 IPv4

    购买完成后，在 VPS 后台重装系统：

    Ubuntu 24.04 LTS 64-bit

    也可以选择 Debian 12/13。

    重装完成后保存以下信息：

    服务器公网 IP
SSH 端口：一般为 22
Root 用户密码

    同时在 VPS 防火墙或安全组中放行：

    22/TCP：FinalShell 连接
80/TCP：申请和续期 SSL 证书

    重装系统会清空服务器上的全部数据，旧服务器请先备份。

    第二步：使用 FinalShell 连接服务器

    从官网下载并安装 FinalShell：

    https://www.hostbuf.com/

    在 FinalShell 中填写 VPS 的服务器 IP、SSH 端口、用户名和密码，连接成功后，在终端输入第一条指令：

    apt update -y && apt upgrade -y && apt install sudo curl -y

    该指令用于更新 Ubuntu 系统，并安装后续部署需要的工具。

    具体连接和操作过程请跟随视频演示。

    第三步：安装 3X-UI 面板

    服务器更新完成后，在 FinalShell 中输入第二条指令：

    bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh) v3.4.2

    该指令会自动下载并安装最新稳定版 3X-UI 面板。

    安装过程中的数据库、面板端口、账号密码和其他选项，请跟随视频中的实际演示完成。

    安装结束后，请保存终端显示的面板用户名、密码、端口、访问路径和完整访问地址。

    高频问题

    1. FinalShell 无法连接服务器

    请检查：

    • 服务器 IP 是否填写正确。
    • SSH 端口是否正确，默认一般为 22。
    • 用户名是否为 root。
    • Root 密码是否正确。
    • VPS 防火墙或安全组是否放行 SSH 端口。

    2. 重装系统后提示服务器指纹发生变化

    可以删除 FinalShell 中原来的连接并重新创建。

    也可以在本地 PowerShell 执行：

    ssh-keygen -R <服务器IP>

    请将 <服务器IP> 替换成实际的 VPS IP。

    3. 3X-UI 安装命令无法下载

    先确认第一条指令已经执行完成，然后重新运行安装命令。

    如果依然失败，通常是 VPS 暂时无法连接 GitHub，可以稍后重试或更换服务器网络。

    4. 安装完成后面板打不开

    在 FinalShell 中执行：

    x-ui settings

    检查面板端口、访问路径和完整访问地址，同时确认 VPS 安全组已经放行面板端口。

    5. 忘记面板用户名或密码

    在 FinalShell 中执行：

    x-ui

    进入管理菜单后，选择：

    Reset Username & Password

    进阶技巧：安装 SSL 证书

    SSL 证书有什么作用？

    为 3X-UI 安装 SSL 证书主要有两个作用：

    1. 保护面板登录安全

    安装 SSL 后，3X-UI 面板可以通过 HTTPS 访问，对账号、密码和登录信息进行加密，避免通过明文 HTTP 传输。

    1. 用于搭建需要 TLS 的节点

    Hysteria2（Hy2）使用 TLS，因此服务器需要正确配置证书和私钥，否则客户端通常无法正常连接。

    除了 Hysteria2，Trojan、VLESS + WS + TLS、VLESS + gRPC + TLS 等节点也可能需要使用 SSL 证书。

    VLESS + REALITY 不需要自己的域名证书，因为 REALITY 使用的是另一套安全机制。

    第一步：免费获取域名并接入 Cloudflare

    如果还没有域名，请先观看下面这期视频，按照视频教程免费获取域名，并将域名添加到 Cloudflare：

    ▶ 免费域名获取与 Cloudflare 激活教程

    完成后，在 Cloudflare 的 DNS 页面添加一条 A 记录：

    类型：A
名称：自定义，例如 vpn
IPv4 地址：填写 VPS 公网 IP
代理状态：仅 DNS

    假设你的域名是：

    example.com

    填写 vpn 后，最终使用的完整域名就是：

    vpn.example.com

    申请证书期间，Cloudflare 代理状态必须设置为“仅 DNS”，也就是灰色云朵，不要开启橙色云朵代理。

    第二步：放行 80 端口

    申请 SSL 证书前，需要在 VPS 服务商的防火墙或安全组中放行：

    80/TCP

    3X-UI 需要使用该端口验证域名是否已经正确解析到当前服务器。

    第三步：在 3X-UI 中申请证书

    使用 FinalShell 连接服务器，然后执行：

    x-ui

    进入 3X-UI 管理菜单后选择：

    SSL Certificate Management

    然后选择：

    Get SSL (Domain)

    根据提示输入已经解析到 VPS 的完整域名，例如：

    vpn.example.com

    证书验证端口使用默认的：

    80

    如果询问是否修改 ACME 重载命令：

    Would you like to modify --reloadcmd for ACME?

    输入：

    n

    如果询问是否将证书用于 3X-UI 面板：

    Would you like to set this certificate for the panel?

    输入：

    y

    等待终端显示证书申请成功，3X-UI 面板就可以通过类似下面的地址访问：

    https://vpn.example.com:面板端口/随机访问路径

    第四步：将证书用于 Hysteria2

    证书申请成功后，常见的证书文件路径为：

    /root/cert/你的完整域名/fullchain.pem
/root/cert/你的完整域名/privkey.pem

    例如：

    /root/cert/vpn.example.com/fullchain.pem
/root/cert/vpn.example.com/privkey.pem

    在 3X-UI 中创建 Hysteria2 节点时，需要启用 TLS，并分别选择对应的证书文件和私钥文件。

    证书文件：fullchain.pem
私钥文件：privkey.pem

    给面板启用 HTTPS 和给 Hysteria2 指定证书是两个设置。申请一次证书后可以共用这些证书文件，但创建 Hy2 节点时仍需确认已经填写正确的证书路径。

    SSL 证书申请失败怎么办？

    请依次检查：

    • 域名是否已经添加到 Cloudflare。
    • A 记录是否指向当前 VPS 公网 IP。
    • Cloudflare 是否设置为“仅 DNS”。
    • VPS 安全组是否放行 80/TCP。
    • 系统防火墙是否拦截 80 端口。
    • 80 端口是否被其他程序占用。

    检查 80 端口：

    ss -lntp | grep ':80'

    处理完成后再次执行：

    x-ui

    重新进入 SSL Certificate Management 申请域名证书。

    常用管理指令

    x-ui
x-ui status
x-ui settings
x-ui restart
x-ui log
x-ui update

    更新前建议先在 3X-UI 面板中备份数据库，并优先更新到稳定版本。

    IP 检测

    节点配置完成并连接后，可以打开 Ping0 检查出口 IP：

    https://ping0.cc/

    VPS 通常会被识别为“IDC 机房 IP”，这是正常现象。
