# 第一步：购买并重装 VPS

购买一台带有独立公网 IPv4 的 VPS，个人使用建议配置：

```text
CPU：1 核及以上
内存：1GB 及以上
硬盘：10GB 及以上
系统：Ubuntu 24.04 LTS
公网 IP：必须有独立 IPv4
```

购买完成后，在 VPS 后台重装系统：

```text
Ubuntu 24.04 LTS 64-bit
```

也可以选择 Debian 12/13。

重装完成后保存以下信息：

```text
服务器公网 IP
SSH 端口：一般为 22
Root 用户密码
```

同时在 VPS 防火墙或安全组中放行：

```text
22/TCP：FinalShell 连接
80/TCP：申请和续期 SSL 证书
```

> 重装系统会清空服务器上的全部数据，旧服务器请先备份。

# 第二步：使用 FinalShell 连接服务器

从官网下载并安装 FinalShell：

[https://www.hostbuf.com/](https://www.hostbuf.com/)

在 FinalShell 中填写 VPS 的服务器 IP、SSH 端口、用户名和密码，连接成功后，在终端输入第一条指令：

```bash
apt update -y && apt upgrade -y && apt install sudo curl -y
```

该指令用于更新 Ubuntu 系统，并安装后续部署需要的工具。

具体连接和操作过程请跟随视频演示。

# 第三步：安装 3X-UI 面板

服务器更新完成后，在 FinalShell 中输入第二条指令：

```bash
bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh) v3.4.2
```

该指令会自动下载并安装最新稳定版 3X-UI 面板。

安装过程中的数据库、面板端口、账号密码和其他选项，请跟随视频中的实际演示完成。

> 安装结束后，请保存终端显示的面板用户名、密码、端口、访问路径和完整访问地址。

# 高频问题

## 1. FinalShell 无法连接服务器

请检查：

- 服务器 IP 是否填写正确。
- SSH 端口是否正确，默认一般为 `22`。
- 用户名是否为 `root`。
- Root 密码是否正确。
- VPS 防火墙或安全组是否放行 SSH 端口。

## 2. 重装系统后提示服务器指纹发生变化

可以删除 FinalShell 中原来的连接并重新创建。

也可以在本地 PowerShell 执行：

```powershell
ssh-keygen -R <服务器IP>
```

请将 `<服务器IP>` 替换成实际的 VPS IP。

## 3. 3X-UI 安装命令无法下载

先确认第一条指令已经执行完成，然后重新运行安装命令。

如果依然失败，通常是 VPS 暂时无法连接 GitHub，可以稍后重试或更换服务器网络。

## 4. 安装完成后面板打不开

在 FinalShell 中执行：

```bash
x-ui settings
```

检查面板端口、访问路径和完整访问地址，同时确认 VPS 安全组已经放行面板端口。

## 5. 忘记面板用户名或密码

在 FinalShell 中执行：

```bash
x-ui
```

进入管理菜单后，选择：

```text
Reset Username & Password
```

# 进阶技巧

## 给 3X-UI 面板安装 SSL 证书

SSL 可以对面板账号、密码和登录信息进行加密，避免通过明文 HTTP 传输。

如果安装 3X-UI 时暂时跳过了 SSL，可以稍后在 FinalShell 中执行：

```bash
x-ui
```

进入 3X-UI 管理菜单，然后选择：

```text
SSL Certificate Management
```

### 方法一：使用公网 IP 申请证书

适合没有域名的用户。

进入 SSL 管理后，选择：

```text
Get SSL for IP Address
```

按照提示操作：

1. 确认程序识别到的是 VPS 公网 IPv4。
2. 没有 IPv6 时直接按回车跳过。
3. 验证端口使用默认的 `80`。
4. 等待证书申请和面板配置完成。
5. 使用新的 HTTPS 地址访问面板。

申请前需要在 VPS 服务商的防火墙或安全组中放行：

```text
80/TCP
```

IP 证书有效期较短，但会自动续期，因此建议保持公网 `80/TCP` 端口畅通。

### 方法二：使用域名申请证书

适合已经拥有域名的用户。

申请前先将域名的 A 记录解析到 VPS 公网 IPv4，然后在 SSL 管理中选择：

```text
Get SSL (Domain)
```

根据提示输入域名，验证端口使用默认的 `80`。

如果询问是否修改 ACME 重载命令，输入：

```text
n
```

如果询问是否将证书用于面板，输入：

```text
y
```

完成后使用类似下面的地址访问：

```text
https://你的域名:面板端口/随机访问路径
```

如果域名使用 Cloudflare，申请证书时建议暂时设置为“仅 DNS”，不要开启代理。

### SSL 申请失败怎么办？

首先检查 80 端口是否被占用：

```bash
ss -lntp | grep ':80'
```

然后确认：

- VPS 安全组已经放行 `80/TCP`。
- 系统防火墙没有拦截 80 端口。
- 公网 IP 填写正确。
- 域名已经解析到当前 VPS。
- 80 端口没有被 Nginx 等程序占用。

处理完成后重新进入：

```bash
x-ui
```

再次选择 `SSL Certificate Management` 申请证书。
